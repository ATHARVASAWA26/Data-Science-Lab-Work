
# Lab 5: Regression Analysis

## Description
This lab focuses on implementing regression techniques and applying them to real-world datasets.

## Files Included
- Lab5_Regression_Analysis.ipynb  
  Demonstrates basic regression concepts and implementation.

- Boston_Housing_Model.ipynb  
  Applies regression on the Boston Housing dataset to predict housing prices.

## Dataset
- Boston Housing Dataset
- Contains features such as crime rate, number of rooms, and other attributes used for predicting house prices.

## Steps Performed
1. Data Cleaning
2. Exploratory Data Analysis
3. Data Visualization
4. Model Building (Linear Regression)
5. Prediction
6. Model Evaluation

## Results
- Successfully predicted housing prices
- Observed relationship between features and target variable

## Tools Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib / Seaborn

## Conclusion
Regression models are effective for predicting continuous values and analyzing relationships between variables.
